Google Calendar credentials live here. Nothing in this directory is committed —
`secrets/` is git-ignored.

* `google_client_secret.json` — the OAuth client (type: Desktop app) downloaded
  from Google Cloud Console.
* `google_token.json` — written by `cd backend && python google_auth.py` after
  you grant access.

See the "Google Calendar" section of the README for the full setup.
